## 1. 合计/统计行与列不再被判成异常值（`fdf5897`）

### 背景

`合计 2400`、`平均分 78.3`、`总分 569` 这些是**算出来的数**，和逐行数据不是一个量级。用「中位数 + MAD」的稳健判据去判，必然把它们标成异常 —— 不是数据错，是判据用错了对象。

更糟的是它们还会污染统计本身：一个 `合计` 落进数值蓄水池，会把 min/max 拉飞，把中位数和 MAD 带偏，进而让**正常数据**被判成异常。

### 识别规则

| 对象 | 判定依据 | 处理 |
|---|---|---|
| **合计行** | 每行**前两列**的标签命中关键词：合计 / 总计 / 小计 / 共计 / 总和 / 汇总 / 统计 / 平均 / 均值 / 中位数 / 标准差 / 方差 / 最大 / 最小 / 最高 / 最低 / 总数 / 总人数 / 总成绩 / 总分 / 及格率 / 优秀率 / 占比，或英文 `total / sum / subtotal / average / avg / mean / max / min / count`（标签长度 ≤ 20，只看前两列，避免误伤「统计部」这类普通数据） | 值**不进蓄水池、不进 min/max、不计异常** |
| **合计列** | 列名命中同一组关键词，**且该列判定为数值列**（「统计项」这种文本列不标） | 整列不做异常值判定，中位数/均值照常算 |
| **统计汇总表** | 表头是「统计项 / 指标 / 项目 / 名称」+「结果 / 数值 / 值 / 合计 / 总计 / 数据」这种窄表（列数 ≤ 4） | 整表不做异常值判定 |

### 对统计口径的影响

- 合计行的数值**不参与**中位数 / MAD / min / max 的计算（否则判据被带偏）
- 合计行**不计入**异常值数量
- 合计列与统计汇总表：描述统计照常（中位数、均值、标准差都能看），只是不判异常

### 界面联动

| 位置 | 行为 |
|---|---|
| 表格 | 合计行 / 合计列不再标红 |
| 异常值列表、异常值总数 | 跳过合计行 |
| 直方图与散点 | 跳过合计行（不会被 2400 拉长坐标轴） |
| 列画像 | 合计列给 **info 级**提示「数值本身是对的，不参与异常值判定」，不是警告 |
| 顶部提示条 | 「识别到 N 行合计/统计行，已从异常值判定和中位数/标准差里排除」 |


### 自测

新增 16 项断言，其中特意留了**对照断言**，证明不是把判据整体关掉：

```
✓ 同一行的值当普通数据会被判异常       ← 241 当数据时确实算异常
✓ 标为合计行后不再判异常
✓ 普通表的 999 仍然是异常值
```

### 已知边界

1. **误判风险**：真实数据的标签里若含「统计 / 汇总」等词（例如部门写「统计部」），那一行也会被排除。已把检查限制在前两列 + 标签 ≤20 字，风险很低但没有归零；需要的话可以在显示设置里加「手动指定合计行」开关。
2. **右对齐的合计**（合计写在最后一列）目前识别不到 —— 只看前两列。
3. **表头写「总计」的整列**会被当成合计列（如「总计销量」），如果它其实是原始数据列，就不会被判异常 —— 属于有意的取舍。

## 2. 辅助功能面板（`df62e9e`）

### 交互

右栏新增一个和「行筛选 / 列操作」同款的可折叠面板：

- 默认收起，标题右侧显示 **点击**；展开后变成 **收起**，再点又变回 **点击**
- 实现用原生 `<details>` + `onToggle` 同步文案，和既有面板完全一致
- 顺带把「行筛选 / 列操作」右上角固定不变的「点开」也改成了 点击 / 收起 联动

### ① 清洗模板 · 一套规则重复用

| 按钮 | 行为 |
|---|---|
| 保存为模板 | 把当前已应用的步骤按**列名**存成模板；没有步骤时禁用并提示先做几步 |
| 套用模板… | 打开模板列表，可应用到当前数据源或全部数据源 |

复用既有的模板弹窗（内置「基础清理」、删除模板、批量应用都在里面）。模板只记录「怎么清洗」，不含任何数据。

### ② 清洗前后对比（原面板并入 + 左右分屏）

原来的「清洗前后对比」独立面板已删除，内容合并进本模块：

- 保留 5 项 Delta：行数 / 空单元格 / 重复行 / 异常值 / 质量分，以及撤销 / 重做
- 新增「左右分屏对比…」弹层：
  - 左：原始数据，**被删掉的行标红**
  - 右：清洗后，**改过的单元格标绿**
  - 两边独立滚动；列被删/改名时按列名对齐，不会错位
  - 顶部汇总：`原始 300 行 → 清洗后 298 行 | 删除 2 行 | 改动 64 格 | 空单元格 32 → 0`
  - 超过 300 行只预览前 300 行，并提示用「导出 Excel」看全量

### ③ 校验报告

自动生成一段可直接粘进实验记录 / 答辩材料的文本，右上角「复制」一键复制（带 `已复制 ✓` 反馈；clipboard 不可用时退回 textarea 方案）。
